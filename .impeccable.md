# Impeccable — Dev Theory Coach

Design context for `dev-theory-coach` (THEORY_CORE). All future UI work in this repo should read this file first.

## Design Context

### Users

A working software engineer preparing for interviews, often in a 15–25 minute gap. They already write code. They need to name the concept a prompt is asking for, say the cost or the force, and reject the usual wrong pick. They are not a student meeting an array for the first time, and they are not here to grind a problem bank — that is the sibling app leetcode-coach.

Every number, system, and prompt on screen is a SAMPLE. The app must never look like a live architecture review, a brokerage, or a judge of their job performance.

### Brand personality

Focused. Honest. Quiet.

- Says SAMPLE out loud on every practice surface.
- Names the method, the cost, or the force before the answer.
- No trophies, no confetti, no streak popups, no "you're on fire."

### Aesthetic direction

Dark canvas, one cool accent, dense enough to read a guide without scrolling through chrome. Type is a plain sans. Track labels are full words, not icons-only.

Reference apps (local siblings):

- mental-math for the guides hub grouped by track and for coach rewind
- leetcode-coach for the guide card and the coach-on-the-same-slug CTA
- stocks-trainer only if a case page needs a commit-then-reveal layout

Anti-references: mosaic chip walls, colorful gamified dashboards, animated confetti, streak motion, live-data theater, a fake terminal that pretends to run the learner's code.

### Surfaces

| Surface | Must show | Must not |
|---------|-----------|----------|
| Guides hub | track labels in full, one row per slug, coach CTA per guide | a second list of the same units under a different name |
| Guide | rule, why, SAMPLE example, use, refuse, coach CTA | pasted curriculum prose, a code editor |
| Coach | current step, choices, rewind on wrong, SAMPLE setup | free-text input, LLM, a 404 when the tree is missing |
| Quiz | four choices, a reason after commit, SAMPLE, no timer | a code runner, a countdown |
| Drill | timer, answer, then a 3-step thought chain, SAMPLE | a drill on a family that is not a drill family |
| Case | scenario, commit, then consequence, SAMPLE | the best consequence before commit; a case when the gate is closed, beyond the gate explanation |
| Cheatsheet | ≤12 lines, pick when, skip when | a second essay |
| Home | real next action naming a slug, case-gate chip, path-complete sentence | decorative % |
